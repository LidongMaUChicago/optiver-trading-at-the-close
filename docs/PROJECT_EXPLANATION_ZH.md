# 项目讲解（中文，面试准备用）

## 一句话

预测纳斯达克股票在收盘竞价阶段、未来 60 秒相对指数的价格变动（单位：基点 bp）。
我把 2023 年的 Kaggle notebook 重写成一个可测试、可复现的研究项目。在此基础上，按事先固定好的规则做了一套完整研究：
- 比较了五类模型；
- 做了特征分组实验；
- 测试了股票 embedding；
- 做了模型融合；
- 用严格的统计方法检验结论。

## 三组数字要分开讲

1. **4.7191**：2023/2024 年的历史 public 分数，是当年在 Kaggle 上的结果。
2. **full-v3**：2026 年用全部历史数据、GPU 跑的结果。XGBoost 在最后 20 天的 MAE 是 5.6687，"一律猜 0" 是 5.7904。
3. **本次研究（local-100d）**：在 Mac 上跑，每个模型只用验证期前 100 天的数据训练。
   - 最终模型在最后 20 天的 MAE 是 5.6602；
   - 这 20 天之前已经被 full-v3 用过，所以标为 REUSED，不算全新的测试。

三组数字来自不同的评估方式，不能放在一起比高低。

## 我是怎么做的，为什么这样做

- **先冻结规则，再跑实验。** `configs/study.json` 在出任何结果之前就写好了：
  - 数据的 hash、5 个验证窗口、训练窗口、空一天的间隔；
  - 每类模型要搜索哪些参数、随机种子、统计检验方法、最终模型怎么选。
  - 这样做是为了防止"看了结果再改规则"。
- **嵌套的时间序列验证。** 用前面几个窗口选参数，用后面一个窗口打分（W3–W5）。这样得到的成绩没有被调参污染。
- **先复现。** 用全部历史数据重跑，Ridge 和 full-v3 完全一样，XGBoost 最多差 0.0006 bp（CPU 和 GPU 的计算差别）。复现对上了，说明后面的对比可信。
- **统计单位是"天"，不是"行"。**
  - 同一天的 200 只股票不是独立的，所以先算每天的误差差值，再做 Newey-West 检验和按块的 bootstrap；
  - 多个检验一起看时，用 Holm 方法修正。

## 主要结论（都有数据支持）

1. **XGBoost 最好。**
   - 在嵌套验证中，它比"一律猜 0"好 0.133 bp（约 2%）；
   - 比 Ridge 好 0.067，比 LSTM 好 0.043，比随机森林好 0.024；
   - 每一项在统计上都显著。
2. **提升很均匀。** 100 个验证日每天都比猜 0 好，200 只股票里 198 只更好。买卖价差越大，提升越多。
3. **调参作用很小。** 14 种 XGBoost 设置里，有 11 种的成绩相差不到 0.005 bp。影响大的是损失函数：用平方误差会差 0.02 bp。
4. **特征分组实验：**
   - 时间（竞价阶段）这组特征最关键，去掉它会差 0.012 bp；
   - 过去几个时刻的变化（lag）这组也有用；
   - 跨股票特征被其他特征"替代"了，单独去掉也不会变差。
5. **最重要的特征 `wap_vs_mid_price`，我做了核对：**
   - 它就等于"半个买卖价差 × 买卖量不平衡"，相关系数 0.999996；
   - 它只用当前这一行的数据，不会偷看未来。
6. **股票 embedding 没有用。** 用 5 个随机种子对比，平均差 −0.0006 bp，p = 0.49，方向也不稳定。
7. **LSTM 的序列结构没有用。** 序列长度为 1 时最好。原因是"过去的变化"已经做成了特征，MLP 和单步 LSTM 一样好。
8. **新股票也能预测。** 训练时去掉 40 只股票，模型在这 40 只上的表现几乎不受影响。说明模型学到的是市场微观结构，不是某只股票的特点。
9. **模型融合：** 几个模型简单平均反而更差。只有"每个时刻减去所有股票预测的平均值"这一步稳定有效：它没有参数，在 3 个外层窗口里都更好。最终模型就是 XGBoost 加上这一步。
10. **最后 20 天（REUSED）的结果：** MAE 5.6602，猜 0 是 5.7904，好 0.130 bp，95% 区间是 [0.119, 0.142]，20 天每天都更好。

## 工程方面

- **复现和可追溯：**
  - 一共 440 次训练，0 次失败，大约 12.5 小时计算时间；
  - 每次训练都记在 `reports/study/experiment_index.csv` 里。
- **推理检查：**
  - 模型存盘再读回来，预测完全一样；
  - 一个时刻一个时刻地喂数据（像 Kaggle 那样）和一次性批量预测，结果完全一样（差 0）；
  - 每个时刻（200 只股票）平均 115 ms；
  - 在本地模拟了 Kaggle 的接口，row_id 全部对上。
- **测试：** 28 个测试全部通过。覆盖了"不能偷看未来"、"不跨股票/跨天"、窗口之间的间隔、embedding 处理新股票等。

## 局限，要主动说

- 训练窗口是 100 天，不是全部历史，因为是在笔记本电脑上跑的。
- 最后 20 天之前已经用过，没有全新的外部测试集。
- MAE 低不等于能赚钱。要证明能赚钱，还需要单独研究交易执行和成本。
